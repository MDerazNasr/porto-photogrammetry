# Source, Privacy, and Refresh Policy

## Provenance

This wiki was generated from the private `#porto-photogrammetry` Slack channel. The local archive and curated refreshes cover 21 May 2025 through 24 September 2026 and include top-level messages, expanded threads, file metadata, attachments permitted by the connector, and shared links.

The curated pages paraphrase technical findings and project decisions. They are not verbatim meeting minutes, and AI-assisted summaries should be checked against source evidence before being used in publications or formal attribution.

## Public-repository boundary

This GitHub repository is public. The following local paths are therefore ignored:

- `raw/`: verbatim private-channel message and thread history.
- `attachments/`: Slack-hosted reports, images, meshes, and other files.
- `inventory/`: detailed Slack file manifests and identifiers.
- `links.md`: full catalog including private dataset and share URLs.

Do not force-add these paths to Git without approval from the project lead and affected contributors. They may contain personal information, unpublished results, private share links, or material with unclear redistribution rights.

## Refresh workflow

1. Read new channel messages since the previous cutoff.
2. Expand every new thread before marking an issue resolved.
3. Import permitted attachments into the local archive using Slack-ID-prefixed names.
4. Update the private link and attachment inventories.
5. Modify curated pages only when the new evidence changes a decision, result, action item, role, or stable resource.
6. Remove email addresses, access tokens, private share links, and verbatim personal conversation from public pages.
7. Record the new cutoff date in this file and the wiki home page.

## Known limitations

- Slack attachment reads are limited to 10 MB through the connector.
- External links may require separate authentication and can expire.
- Historical repository and meeting links may be stale.
- The archive captures Slack state at import time; edits and deletions made later are not automatically synchronized.
